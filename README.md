# Sustainable Materials API

A free API for architects and designers to look up sustainable and biomaterial data — strength, cost, and carbon footprint — for use in material selection, formulation reference, and parametric design workflows. Built as part of ongoing research into low-carbon 3D-printed building materials, such as mycelium composites and low-carbon concrete.
